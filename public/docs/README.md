# Documents served directly to visitors

Anything in this folder is public at `https://aqeaw.com/docs/<filename>`.

## user-guide.pdf

The written user guide linked from the footer. The exact filename matters —
it is referenced by `GUIDE_PDF_PATH` in `lib/userGuide.ts`.

Keep it under about 25 MB. If the source is a Word file, export it to PDF
first so it opens in the browser instead of downloading.
